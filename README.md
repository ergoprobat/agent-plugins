# agent-plugins

Claude Code, Cursor, Copilot and Kiro plugins that keep AI coding agents within ergo decisions.

> Status: skeleton. The marketplace and plugins land in a later change.

Agent marketplaces install from this repository. It will hold the Claude Code marketplace and the install surfaces for the other agents. Plugins call a released CLI and the local MCP server.
